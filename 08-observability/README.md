# 08 — Observability

Entrenamiento orientado a obtener evidencia operativa antes y durante incidentes.

## Roadmap

- métricas;
- logs;
- Prometheus;
- Grafana;
- Loki;
- troubleshooting guiado por señales.

La observabilidad debe utilizarse para responder preguntas concretas sobre comportamiento y fallas, no solamente para mostrar dashboards.
