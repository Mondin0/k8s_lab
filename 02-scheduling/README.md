# 02 — Scheduling

Entrenamiento sobre cómo Kubernetes decide dónde ejecutar workloads y qué ocurre cuando no puede hacerlo.

## Roadmap

- requests y limits;
- `FailedScheduling` por recursos insuficientes;
- nodeSelector;
- taints y tolerations;
- affinity y anti-affinity.

Cada escenario debe incluir al menos una falla de scheduling reproducible y su evidencia en Events.
