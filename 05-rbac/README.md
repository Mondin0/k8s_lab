# 05 — RBAC

Entrenamiento sobre identidad y autorización dentro del cluster.

## Roadmap

- ServiceAccounts;
- Roles y ClusterRoles;
- RoleBindings y ClusterRoleBindings;
- errores `Forbidden`;
- `kubectl auth can-i`.

Los escenarios deben aplicar least privilege y demostrar permisos efectivos con comandos verificables.
